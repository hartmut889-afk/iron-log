# 鐵日誌

個人健身課表與訓練紀錄。單一 HTML 檔、沒有後端、沒有帳號、沒有追蹤。

**打開就能用：** https://hartmut889-afk.github.io/iron-log/

## 它能做什麼

- **一到日的課表**：週曆選日期，或在課表區左右滑動換日
- **記錄最大重量與組數**：每組填重量 × 次數，練完打勾。最大重量與估算 1RM（Epley 公式）會從所有打勾的組數自動算出來
- **配重建議**：依估算 1RM 給力量／肌力／增肌／代謝／熱身五種重量組數搭配，點一下直接套用
- **40 個動作的資料庫**：每個動作有姿勢示意圖、出力方向、目標肌群、動作要領、常見錯誤與呼吸節奏
- **課表範本**：內建推日／拉日／腿日，也能把任何一天存成自己的範本
- **離線可用**：第一次打開後就會快取，健身房沒訊號也能開

## 資料存在哪裡

**存在你自己的瀏覽器裡（localStorage），不會上傳到任何地方。** 這代表：

- 換手機、換瀏覽器、清除瀏覽器資料 → 資料不會跟著走
- 無痕視窗、或把頁面嵌在沙箱 iframe 裡 → 根本存不了。這種情況頁面頂端會出現紅色警告，**不會安靜地把資料吃掉**
- 想搬家或備份：設定 → 匯出備份檔，換裝置後用「從檔案還原」

程式每天第一次存檔時會自動留一份前一天的快照，主檔壞掉時會自動回復。

## 加到手機主畫面

- **iPhone**：Safari 開啟 → 分享 → 加入主畫面
- **Android**：Chrome 開啟 → 選單 → 安裝應用程式

加完之後會像一般 App 一樣全螢幕開啟。

## 想自己改一份

整個程式就是 `index.html` 一個檔案，沒有 build 步驟。Fork 之後改完推上 `main`，GitHub Actions 會自動部署到你自己的 Pages。

動作資料在檔案裡的 `DB` 陣列，人形示意圖由 `figureSVG()` 依關節角度即時算出來（角度一律是「畫面角度」：0 朝下、90 朝右、180 朝上）。
